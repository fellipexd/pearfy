# DI baseline — 2026-09-25

- Host: MacBook Air, Apple M4, 16 GiB RAM, arm64.
- OS: macOS 27.0 (26A5425a).
- Toolchain: Apple Swift 6.4.0.34.1.
- Build: SwiftPM `release`.
- Source revision: unversioned working tree.
- Capture: 5 timed samples per scenario; generated raw CSV is adjacent.
- Peak RSS is the process high-water mark, cumulative across scenarios in that process; it is not RSS attributed to an individual operation.

## Medians

| Cenário | Operações | Mediana | Peak RSS observado |
|---|---:|---:|---:|
| Registry build + graph validation, 10 registrations | 10 | 0.052 ms | 6,684,672 B |
| Registry build + graph validation, 100 registrations | 100 | 0.834 ms | 7,110,656 B |
| Registry build + graph validation, 1,000 registrations | 1,000 | 9.604 ms | 8,224,768 B |
| Resolve singleton já inicializado | 10,000 | 15.926 ms | 9,420,800 B |
| Resolve transient | 10,000 | 17.654 ms | 9,437,184 B |
| Contenção: resolves concorrentes do mesmo singleton | 100 | 3.298 ms | 9,453,568 B |

Na contenção, as cinco rodadas registraram exatamente uma chamada de factory. Os valores são uma baseline local para comparações na mesma máquina e configuração; não representam SLA nem comparação cross-language.
